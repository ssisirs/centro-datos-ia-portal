# Portal de Datos e Inteligencia Artificial

Página web que replica el diseño y estilo del Portal de Datos e Inteligencia Artificial, basada en la presentación PPT del Centro de Datos e Inteligencia Artificial (CDIA).

## 📋 Características

- **Diseño responsivo**: Se adapta a dispositivos móviles, tablets y escritorio
- **Paleta de colores corporativa**:
  - Azul marino: #1a2a5e
  - Turquesa/Cyan: #4ba9b8
  - Rosa/Magenta: #d94b7a
  - Blanco y grises neutros

- **Elementos incluidos**:
  - Header con navegación
  - Sección de filtros y búsqueda
  - Grid de tarjetas de reportes
  - Footer corporativo

## 🎨 Estructura

```
centro-datos-ia-portal/
├── index.html      # Página principal
├── styles.css      # Estilos personalizados
└── README.md       # Este archivo
```

## 🚀 Cómo usar

1. Clona el repositorio:
```bash
git clone https://github.com/ssisirs/centro-datos-ia-portal.git
```

2. Abre `index.html` en tu navegador preferido

3. Personaliza el contenido según tus necesidades:
   - Reemplaza las imágenes placeholder con imágenes reales
   - Actualiza los textos de los reportes
   - Modifica los enlaces de navegación

## 🎯 Personalizaciones recomendadas

### Agregar tus propias imágenes
En el archivo `index.html`, reemplaza:
```html
<img src="https://via.placeholder.com/400x200" alt="Reporte">
```

Con tu URL de imagen real:
```html
<img src="tu-imagen.jpg" alt="Descripción">
```

### Actualizar información
- Modifica el título y descripción en el header
- Actualiza los datos de los reportes
- Cambia los enlaces de navegación

## 📱 Responsive Design

La página se adapta automáticamente a:
- Pantallas grandes (1024px+): 3 columnas
- Tablets (768px - 1024px): 2 columnas
- Móviles (<768px): 1 columna

## 🔧 Tecnologías

- HTML5
- CSS3 (Grid, Flexbox)
- Diseño mobile-first
